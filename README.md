# AI API Cost Calculator

> Calculate and compare API pricing across 20+ LLM models — OpenAI, Anthropic, Google, DeepSeek, and more.
>
> Live: https://aicostcalc.net (coming soon)

## Quick start

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # production build
npm run type-check   # TypeScript check
npm run lint         # ESLint
```
